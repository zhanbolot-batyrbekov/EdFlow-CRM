**EdFlow CRM** — это легковесная, быстрая и безопасная веб-система для автоматизации учебных центров, языковых школ и курсов. Проект спроектирован с упором на производительность, безопасность данных и удобный интерфейс для трех ролей пользователей: администраторов, преподавателей и студентов.

---

## ✨ Ключевые возможности

- 🔐 **Многоуровневая ролевая модель (RBAC):**
  - **Администратор:** Полный контроль над структурой центра, финансами, аналитикой, архивом и глобальными настройками.
  - **Преподаватель:** Доступ к своим группам, электронному журналу посещаемости и индивидуальному расписанию.
  - **Студент:** Персональный личный кабинет с расписанием занятий и статусом обучения.
- 📅 **Интерактивное расписание:**
  - Недельная сетка занятий с фильтрацией по группам.
  - Управление аудиториями, предметами и преподавателями.
- 📊 **Электронный журнал посещаемости:**
  - 3-статусная система отметок (`присутствовал` / `отсутствовал` / `не отмечено`).
  - Автоматический расчет процента посещаемости за месяц.
- 💰 **Продвинутый финансовый модуль:**
  - Учет оплат, расчет задолженностей и средних чеков.
  - Алгоритм «жадного заполнения» для распределения средств по периодам.
- 📱 **Адаптивный UI / UX:**
  - Поддержка светлой и темной тем оформления.
  - Оптимизация под мобильные устройства (мощная нижняя панель навигации).

---

## 🛠 Технологический стек

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (CSS Variables, Flexbox, Grid).
- **Backend:** PHP (REST-подобная архитектура через единый контроллер `api.php`, транзакции PDO).
- **Database:** MySQL / MariaDB (с оптимизированными индексами и внешними ключами).

## 📁 Структура проекта

```text
├── api.php              # Главный защищенный бэкенд-контроллер (API)
├── config.php           # Подключение к БД (PDO) и базовые константы
├── index.html           # Главный шаблон приложения и модальные окна
├── style.css            # Таблица стилей (темная/светлая тема, адаптив)
└── js/
    ├── utils.js         # Утилиты, форматирование дат, XSS-защита
    ├── state.js         # Глобальное состояние и финансовые расчеты
    ├── api-client.js    # HTTP-клиент (Fetch API) и управление токенами
    ├── validation.js    # Фреймворк клиентской валидации форм
    ├── ui.js            # Компоненты интерфейса, тосты, темы, часы
    ├── groups.js        # Управление группами и курсами
    ├── attendance.js    # Логика журнала посещаемости
    ├── finance.js       # Финансовые отчеты и платежи
    ├── students.js      # Управление учениками и преподавателями
    ├── schedule.js      # Модуль расписания занятий
    ├── profile.js       # Настройки профиля и аватарки
    └── app-init.js      # Точка входа, роутинг и инициализация приложения
```
